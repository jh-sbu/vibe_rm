# Math.Acos

Public source consulted 2026-10-24: [Creation Kit Math reference, revision 23257](https://ck.uesp.net/w/index.php?title=Math_Script&oldid=23257).
The documented result is an angle in degrees. Implementation converts Rust's
arccosine result from radians. Synthetic tests cover both endpoints and interior values.
The installed Math.pex declaration was inspected read-only to confirm the native;
no game content is reproduced here and no engine binary was inspected.
